# Moodle Download

Moodle のコースページからファイルを一括・選択ダウンロードする Chrome 拡張機能です。

## 機能

- コースページ（`/course/view.php`）上のファイルを自動検出
- チェックボックスでダウンロードするファイルを選択
- 「すべて選択」「選択解除」で一括操作
- 保存先フォルダをユーザーが指定（File System Access API）
- 元のファイル名のまま保存

## 必要環境

- Google Chrome
- Node.js 18+

## セットアップ

```bash
npm install
npm run build
```

## Chrome への読み込み

1. Chrome で `chrome://extensions` を開く
2. 「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」
4. `dist` フォルダを選択

## 使い方

1. 大学の Moodle にログインする
2. ファイルをダウンロードしたい **コースページ** を開く
3. 拡張機能のアイコンをクリックしてポップアップを開く
4. 「選択」ボタンで保存先フォルダを指定
5. ダウンロードしたいファイルにチェックを入れる
6. 「ダウンロード」をクリック

## 開発

```bash
npm run dev    # ウォッチモードでビルド
npm run typecheck
```

## 注意事項

- コースページ以外ではファイル検出は動作しません
- フォルダ型リソースは中身の一覧が別ページにあるため、コースページからはフォルダ自体のみ表示されます（フォルダページを開いて個別にダウンロードしてください）
- Moodle のログインセッションが必要です（ブラウザでログイン済みであること）

## 技術スタック

- TypeScript
- Chrome Extension Manifest V3
- Vite + @crxjs/vite-plugin
